Module 02

Homography Lab

เปรียบเทียบพิกัดต้นฉบับ ภาพที่ถูกบิด และผลหลังใช้ \(H^{-1}\)

วิธีใช้งาน Module 02: Homography Lab

  1. เปรียบเทียบ 3 รูป: ดูความแตกต่างระหว่าง 01 Original (วัตถุจริง) $\rightarrow$ 02 Distorted (ภาพเอียง $L_{\text{raw}}$) $\rightarrow$ 03 Recovered (กู้คืนด้วย $H^{-1}$)
  2. ปรับระดับการเอียง: ลองเปลี่ยน Homography จาก H1 (เอียงน้อย) เป็น H3 (เอียงมาก) แล้วสังเกตว่าค่า $L_{\text{raw}}$ เพี้ยนไปไกลแค่ไหน
  3. สรุปผล: ค่า $L_{\text{rec}}$ ในช่องที่ 3 จะถูกกู้คืนกลับมาเท่ากับค่าจริง $L_0$ เสมอเมื่อใช้เมทริกซ์ผกผัน $H^{-1}$
\(\tilde{Q} \sim H \tilde{P} \implies \tilde{P} \sim H^{-1} \tilde{Q}\)

Module 03

Error Bound Lab

ทดลองกับข้อพิสูจน์หลักของโครงงาน: ถ้าแต่ละจุดคลาดไม่เกิน \(\varepsilon\) แล้ว LII จะคลาดไม่เกิน \(10\varepsilon\)

วิธีใช้งาน Module 03: Error Bound Lab

  1. ความหมายของ $\varepsilon$ (Epsilon): รัศมีวงกลมประสีแดงรอบจุด คือขอบเขตความคลาดเคลื่อนสูงสุดที่จุดนั้นอาจขยับได้
  2. ทดลองขยับจุด: กดปุ่ม "สุ่มจุดในวง $\varepsilon$" หรือลากจุดสีแดงด้วยมือ แล้วสังเกตกล่อง Actual Error ($|\hat{L} - L_0|$)
  3. สรุปทฤษฎีบท: ไม่ว่าจะสุ่มหรือลากจุดไปทิศทางใด ค่าความคลาดเคลื่อนจริงจะ ไม่มีทางเกินค่าเพดาน $10\varepsilon$ (PASS เสมอ)

Module 04

Monte Carlo Lab

สุ่ม error ของแต่ละจุดในวงรัศมี \(\varepsilon\) แล้วดู distribution ของ \(|\hat{L} - L_0|\)

วิธีใช้งาน Module 04: Monte Carlo Lab

  1. หลักการ Monte Carlo: จำลองสุ่มการคลาดเคลื่อน $1,000 - 18,000$ รอบในเบราว์เซอร์
  2. เริ่มรัน: เลือกจำนวนรอบ แล้วกดปุ่ม "Run simulation"
  3. อ่านกราฟ: แท่งสีฟ้าต้องอยู่ฝั่งซ้ายของเส้นขอบเขตสีแดง $10\varepsilon$ (Pass Rate 100%)

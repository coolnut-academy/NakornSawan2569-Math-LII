Module 01

LII Measurement (Polyline)

พิกัดจริงบนระนาบ calibration และผลรวมระยะ 5 ช่วงจาก Q ที่ยืนยันล่าสุด

วิธีใช้งาน Module 01: LII Builder

  1. แนวคิดหลัก: ค่า LII ในโปรเจกต์นี้ คือ ผลรวมระยะ Euclidean ระหว่างจุด P₁–P₆ ที่อยู่ติดกัน 5 ช่วง (polyline path length) ซึ่งแตกต่างจาก Little's Irregularity Index ดั้งเดิมที่วัด displacement ระหว่างฟัน
  2. แหล่งข้อมูล: โมดูลนี้รอ Q1-Q6 ที่ยืนยันจากหน้านี้และไม่สร้าง dataset จำลองขึ้นเอง
  3. ผลลัพธ์: แสดงพิกัดหน่วย cm ระยะทั้ง 5 ช่วง และค่า LII (Polyline) ของ snapshot ที่ยืนยัน

Module 02

Image Calibration

ตรวจพิกัด pixel, เมทริกซ์จาก C1-C4 และพิกัด cm หลังใช้ \(H^{-1}\)

วิธีใช้งาน Module 02: Homography Lab

  1. Image points: Q1-Q6 ที่ผู้ใช้วางบนภาพ หน่วย pixel
  2. Calibrated plane: ใช้ขนาดพื้นที่สอบเทียบและ $H^{-1}$ แปลง Q เป็นหน่วย cm
  3. Reference comparison: แสดงเฉพาะเมื่อภาพมี ground truth เช่น Preset; ภาพผู้ใช้จะไม่สร้างค่าจริงอ้างอิงขึ้นเอง
\(\tilde{Q} \sim H \tilde{P} \implies \tilde{P} \sim H^{-1} \tilde{Q}\)

Module 03

Measurement Validation

ตรวจ error และขอบเขตจาก reference จริงเท่านั้น โดยไม่สร้างค่า ground truth จำลอง

วิธีใช้งาน Module 03: Error Bound Lab

  1. Known reference: Preset ที่มีพิกัดจริงสามารถคำนวณ $\varepsilon$, actual error และ $10\varepsilon$ ได้
  2. Uploaded image: หากไม่มี ground truth ระบบจะแสดง Measurement Only และไม่สรุป PASS/FAIL
  3. แหล่งข้อมูล: กราฟและตัวเลขมาจาก Q snapshot ที่ยืนยันล่าสุดเท่านั้น

Module 04

Measurement Uncertainty

จำลองความไวต่อความคลาดเคลื่อนโดยใช้ Q ที่ยืนยันจริงเป็นจุดตั้งต้น

วิธีใช้งาน Module 04: Monte Carlo Lab

  1. หลักการ Monte Carlo: จำลองการคลาดเคลื่อนรอบ Q snapshot จริง $100-18,000$ รอบในเบราว์เซอร์
  2. เริ่มรัน: เลือกจำนวนรอบ แล้วกดปุ่ม "Run simulation"
  3. อ่านกราฟ: แท่งสีฟ้าต้องอยู่ฝั่งซ้ายของเส้นขอบเขตสีแดง $10\varepsilon$ (Pass Rate 100%)

วัดจากภาพถ่ายของคุณ

อัปโหลดหรือถ่ายภาพจากด้านบน แล้วกำหนดมุมเป้าสอบเทียบ 4 จุดและจุดวัด 6 จุดตามลำดับ

ลำดับการวัดจากภาพ

  1. เลือกภาพ: ใช้ภาพที่กล้องอยู่เกือบตั้งฉากกับระนาบเป้าสอบเทียบและเห็นกรอบครบทั้ง 4 มุม
  2. กำหนด $C_1-C_4$: แตะมุมกรอบตามเข็มนาฬิกา เริ่มจากซ้ายบน เพื่อประมาณ $H_{\text{est}}$
  3. กำหนด $Q_1-Q_6$: แตะจุดสัมผัสของฟันหน้าล่างจากขวาไปซ้ายให้ครบ 6 จุด
  4. อ่านผล: ระบบรายงาน $L_{\text{rec}}$ ส่วน PASS/FAIL จะแสดงเฉพาะข้อมูลที่มีพิกัดอ้างอิงจริง
